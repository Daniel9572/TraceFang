# 本地金十软件来源

## 采集方式

适配器只在 Windows 上工作：

1. 查找进程名为 `JinShiShuJu`、窗口类为 `FLUTTER_RUNNER_WIN32_WINDOW` 的行情主窗口；
2. 使用 Windows `PrintWindow` 读取窗口画面；
3. 裁剪观察列表中黄金或白银的价格区域；
4. 用系统自带 Windows OCR 识别数字；
5. 统一小数分隔符，并按品种小数位和安全价格范围校验；
6. 输出部分报价对象：`last` 有值，桌面列表没有可靠提供的 OHLC、成交量和涨跌字段保持为空。

## 运行条件

- 金十数据桌面软件必须正在运行；
- 必须打开行情页；
- 行情窗口不能最小化；被其他窗口遮挡不影响 `PrintWindow`；
- 保持默认观察列表布局，黄金和白银位于前两行；
- Windows 用户语言需要具备 OCR 支持。

来源管理会把上述条件显示为健康状态。失败不会被包装成旧数据；自动模式会继续尝试其他报价来源。

## 明确不做

- 不做 TLS 中间人、证书替换、抓包解密或鉴权绕过；
- 不逆向或依赖金十私有网络协议；
- 不读取进程内存；
- 不从图表像素推断 OHLC/K 线；
- 不把屏幕采样时间冒充上游市场撮合时间。

这个来源定位为低成本、略有延迟的普通分析输入。高精度、完整字段、历史 K 线和审计场景应优先选择结构化授权接口。
