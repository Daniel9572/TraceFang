# 数据来源管理

## 两层模型

- **实时数据源**是唯一面向用户和合约路由的对象。它必须同时输出 `quote + kline`；只有其中一项的实现不是完整实时数据源。
- `capabilities` 表示来源设计上支持的稳定能力；运行时允许以 `degraded` 状态保留仍然真实可用的部分结果。来源级 `history_backfill_configured` 表示恢复合约已绑定历史通道；会话当前是否可用由来源健康状态表达，不能再由一次启动探测永久决定。
- **内部采集通道**只在实时数据源内部负责采集、字段归属、健康诊断与原始证据落库，不是可选数据源。
- 一个实时数据源可以由一个或多个内部通道实现；其构成不属于前端选择契约。
- 每个实时数据源声明稳定的报价服务等级 `quote_service_tier`：`institutional / enhanced / standard / reference`。当前金十统一行情属于 `enhanced`，适合常规分析，但不等同于有明确低延迟 SLA 的机构级行情。
- 路由粒度是“合约”。数据库对每个合约只保留一行 `realtime` 绑定；选择新源时原子替换旧值，不存在多选、优先级回退或 `auto`。
- REST 与 WebSocket 根据合约绑定解析实时数据源，调用方不能通过查询参数指定内部通道或绕过路由。
- 绑定源失败时直接报告，不尝试另一个实时数据源。
- “历史数据”是时间范围而不是 K 线结构。当前和过去的数据都服从同一合约绑定；K 线缓存按实时数据源隔离。
- 当前冻结全局历史治理：不读写 `standard_candles`，不执行多源共识、免费通道补缺或跨源校对。
- 图表工具栏中的“实时数据源”下拉框采用单选交互，只负责查看健康状态、测试连接和原子替换当前合约绑定。

## 当前实时数据源与内部通道

当前按品种提供两套可选实时数据源：

- `jin10_client`（界面名称“金十统一行情”）服务 `XAUUSD`、`XAGUSD`、`USDCNH` 及其派生观察值，同时输出报价事件、当前/过去 K 线、涨跌和日内统计；
- `tonghuashun_futures`（界面名称“同花顺公开行情”）服务 `AU8888`、`AG8888`、`AU2610`、`AG2706`、`USDIND`、`BRN0Y`、`SHCOMP` 与 `IXIC`，直接输出同花顺公开网页的结构化报价与同源一分钟 K 线；运行时不要求本地期货通应用常驻。

品种目录通过 `source_ids` 声明兼容来源；前端只展示当前品种兼容的来源，后端也拒绝写入不兼容的绑定。

其内部使用 `jin10_web` 与 `jin10_local` 两个通道。二者在 `quote_events`、`latest_quotes` 与 `candles` 中按真实渠道分别保存，绝不写成伪造的 `jin10_client` 原始记录。实时价格不可用时来源停滞；日内统计不可用或过期时，结果以 `quality=degraded` 和字段列表说明。过去 K 线来自 `jin10_local` 的同源 K 线协议，当前分钟由 `jin10_web` 价格事件即时生长；这是该实时数据源固定的内部组合，对外统一标记为 `jin10_client`，不会混入其他实时数据源。

金十桌面会话解析属于内部设置，不形成新的来源。显式 Token 优先；macOS 标准客户端已登录时可从当前用户的受信 `local_storage.json` 自动发现。协议以零值身份让服务端从 token 解析账户，不读取任何客户端日志，也不保存用户编号。会话暂时缺失时提供器保持可恢复，客户端重新登录后自动刷新连接。Token 不得进入来源描述、健康状态、异常、日志、数据库或前端。

断线恢复、服务重启追赶、图表可见缺口与向前加载共用同一个后端恢复合约：先查本地统一一分钟事实与覆盖，再按交易日历生成缺失范围，只调用当前合约绑定来源的历史能力，并在同一事务中推进覆盖和权威时刻。前端只表达时间范围，不选择内部通道，也不承担恢复编排。

`jin10_web` 与 `jin10_local` 不出现在 `GET /api/sources`，不能写入合约路由，也不能由前端单独启停。它们仅在内部健康检查、原始审计和历史候选流程中保留渠道身份。

启动时把旧 `quote` 路由迁移为 `realtime`，并把遗留的内部通道绑定迁移为该品种目录声明的默认完整来源。数据库唯一索引继续保证一个合约最多一条绑定。

## 本地 API

- `GET /api/sources?refresh=true|false`：只返回完整、可选实时数据源的能力、连接策略和健康状态；`history_backfill_configured` 表示恢复合约是否已绑定历史通道，不代表会话此刻健康，也不暴露内部通道；
- `POST /api/sources/{source_id}/test?code={code}`：用兼容品种主动测试一个实时数据源的报价与 K 线输出；
- `GET /api/instruments/{code}/source`：读取该合约唯一实时数据源；
- `PUT /api/instruments/{code}/source`：原子替换该合约的唯一实时数据源；
- `GET /api/quotes/{code}`：按合约绑定只读本地聚合最新帧，不接受 `source` 参数；返回 `quote / quality / unavailable_fields / stale_fields`；
- `GET /api/candles/{code}`：按合约绑定读取该实时数据源的专属分钟 K 线缓存，不接受 `source` 参数，也不调用上游；
- `POST /api/candles/{code}/backfill`：显式补取一个缺失时间范围；来源仍由合约绑定决定，不接受客户端来源参数。成功后原子保存原始 K 线、统一 Bar、完成覆盖和序列权威状态。返回 `cached / joined / fetched / advanced / exhausted / deferred` 之一，并提供确认覆盖、排他权威时刻、明确历史下界与可选重试时刻；
- `WS /api/stream/quotes/{code}`：按合约绑定持续发送聚合报价与状态事件，不接受来源参数。

## 成本、限额与连接策略

每个来源均声明 `access_model`：

- `unmetered`：无调用计费或本应用不需要管理上游额度；
- `limited`：存在固定周期请求上限；
- `metered`：按调用量计费。

当前没有启用的限额或付费实时数据源。未来接入此类来源时，额度属于该实时数据源的运行状态，不改变“一个合约一条绑定”的规则。

额度按工具返回 `used / limit / reserve / available / usage_percent / resets_at`。当前 `used` 是本应用进程内计数，不包含同一账号在其他客户端产生的调用，因此 UI 明确标注为本应用记录；上游返回的限流错误始终具有最终权威性。

## 金十 MCP 冻结策略

历史协议实现只保留在归档代码和 [jin10-mcp.md](jin10-mcp.md) 中，方便未来重新评审；当前运行规则为：

- 应用运行时不读取 MCP 开关、Token、地址或额度配置；`.env.example` 不再提供这些字段；
- MCP 不注册为实时数据源或内部通道，`GET /api/sources`、合约路由和前端均看不到 MCP；
- 不执行 `initialize`、`tools/list`、`resources/list` 或 `tools/call`；
- 不采集报价或 K 线，不提供资讯/日历，不进入实时路由、历史补缺或主动校对列表；
- 历史 MCP 原始记录仅作审计归档，不能进入任何实时数据源的当前或过去数据缓存；
- 本地报价通过单一长连接接收，实测通常约每 3～4 秒一帧，不消耗 MCP 工具额度；
- 网页极速报价使用独立公开长连接和变化驱动档；2026-08-06 实测黄金 30 秒 70 帧，平均约 3.68 帧/秒，不消耗 MCP 工具额度；
- 同次采样中，本机后端接收至网页采样器平均 1.27ms、中位 0.96ms、P95 2.52ms；上游源时间只有整秒精度，不能据此伪造精确的公网单向延迟；
- 新页面和新 WebSocket 订阅者从内存或 `latest_quotes` 回放最新帧；分钟 K 线 GET 只读绑定源本地缓存。缺口只允许通过独立回补命令请求同一实时数据源，绝不尝试其他来源。

本机 `.env` 中即使遗留 MCP 字段也会被应用忽略。恢复 MCP 必须先进行新的架构评审和代码变更，不能通过修改环境变量重新启用。

WebSocket 解决浏览器到本机后端的持续传递，不能把低频上游变成逐笔行情。

页面先读取当前合约绑定源的专属 K 线，再用同一实时数据源的报价事件更新当前柱；若请求范围未完成，后台回补后只追加本地新行。只有该来源固定的价格事件推进时间线，日内统计只进入聚合字段；内部细节不暴露为可选来源。同一源时间秒内的多个价格事件以本地接收时间排序，全部参与当前柱高低收计算。新周期第一笔报价独立决定新柱开盘，收盘倒计时完全在浏览器本地计算。历史行插入时保持当前可视范围，不强制缩放或抢走用户焦点。

`GET /api/health` 只公开按逻辑实时数据源聚合的历史计数和序列水位，不公开内部通道代码、供应商符号、会话用户、Token 或本机路径。普通缓存命中不访问上游；完全相同的并发窗口合并，重叠窗口只请求差集。当前可变尾部使用软冷却，失败使用指数退避；报价热路径不等待历史下载或数据库批量事务。
