# REQ-0004 行情源启动和恢复可靠

依据：用户于 2026-10-02 指出数据源启动经常不可用，要求从保障策略、调度和整体架构调整。

应用启动后应按合约绑定持续采集；暂时断线应自动恢复，配置或依赖错误应说明具体原因。数据源健康状态必须来自实际采集结果，不能把配置存在、后台任务存在或一次 HTTP 成功等同于新行情可用。单个品种失败不能阻断其他品种，重试不能形成集中请求。

与行情准确性的共同约束见 [REQ-0003](REQ-0003.md)。

2026-10-02 实施：补齐 SOCKS 依赖和连接心跳；同源错峰轮询、品种独立退避；以实际采集结果生成健康状态；断流时主动使报价过期。本机更新后金十恢复持续供数，同花顺出现空响应后自动恢复。上游暂时无新报价仍显示最后行情及原始时间，不将其包装成在线新报价。
