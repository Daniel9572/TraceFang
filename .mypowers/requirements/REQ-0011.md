# REQ-0011 Rust 后端迁移与重构

2026-10-02 用户明确要求后端迁移到 Rust，从底层改善响应速度、性能和准确性。迁移需覆盖核心行情数据流、查询聚合、实时推送及分析，保留现有产品能力与历史证据。不能将代理旧服务等同于原生迁移完成。

验证：沿用 REQ-0003 的原始行情对照，精确十进制计算、缺失值、交易时段、乱序与修订语义必须保留；迁移前后使用同一数据版本比较。测量实际启动、查询和并发延迟，记录未迁移组件与依赖。前端和已安装版本的迁移状态分别说明。

状态：实施中。现有后端为 Python/FastAPI、PostgreSQL、NATS；先建立 Rust 行情计算与 HTTP 服务并做差异验收，再切换正式入口。已安装 Rust 1.99.0 工具链，未更改用户 shell 配置。
