# REQ-0011 Rust 后端迁移与重构

2026-10-02 用户明确要求后端迁移到 Rust，从底层改善响应速度、性能和准确性。迁移需覆盖核心行情数据流、查询聚合、实时推送及分析，保留现有产品能力与历史证据。不能将代理旧服务等同于原生迁移完成。

验证：沿用 REQ-0003 的原始行情对照，精确十进制计算、缺失值、交易时段、乱序与修订语义必须保留；迁移前后使用同一数据版本比较。测量实际启动、查询和并发延迟，记录未迁移组件与依赖。前端和已安装版本的迁移状态分别说明。

状态：Rust 原生核心、v9 server 与四个迁移工具（共五个封存可执行文件）已构建校验，最终 Web 包已与 v9 组合；既有精度、恢复及所测性能证据，和两份首 512 费用运行的逐笔 Decimal、页面与正常重启验收均已完成。用户取消新增回放测试，复用已有导入、G06 与恢复结果；取消的执行不算通过，本文正确性与完整性契约仍然有效。正式旧数据尾部接管和对账、存储激活及 8000 部署仍在进行，迁移尚未完成。进展见[当前计划](../work/fleet-20261004/current-plan.md)、[存储选择](../design/storage-selection.md)与[存储基准结果](../work/rust-migration/validation/storage/results.md)。
