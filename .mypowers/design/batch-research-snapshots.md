# 固定研究输入与列式扫描

2026-10-03 总控为 REQ-0012 的下一实施包固定边界。当前尚未实施，不把已选 Parquet/Arrow/DuckDB 写成已交付能力。storage_sol 完成导入及回放主线后实施；复用 recovery_sol 的单 MVCC 有界扫描。

从一次 native Store 读事务导出完整指定来源、品种、周期和半开时间范围。快照包含精确 OHLC、显式 NULL、volume 已知/总量覆盖、修订、纳秒时刻、来源与导入/应用证据；时间与序号按有符号 i64/无符号 u64 保存，不经 JS 或浮点。文件按行数和实际字节双重限制批次，不能先把整个历史 JSON 装入内存。

Parquet 保存无损规范列，系数与 scale 必须能覆盖当前精确模型。可额外提供经过逐值验证的 Decimal128 快速列，但不得截位。清单逐列说明可表示范围、刻度、NULL 数量、最大绝对系数和行数。DuckDB 的快速聚合只有在可以证明中间运算与结果均不溢出时启用；除法、超 38 位或不满足范围证明的运算回到共享 Rust 精确路径。不是将不可表示的值填为 NULL 后继续求和。

清单记录 Store epoch、MVCC commit、capture/baseline 证据、系列 generation/correction/append 版本、目录/日历/计算 schema、范围、覆盖、规范行内容 hash、文件字节 hash 和数据新鲜度。规范 hash 不依赖 Parquet 压缩细节。生成临时文件、同步文件、验证行数/内容、原子发布 manifest 并同步目录；失败只保留未发布候选，不向研究端返回半文件。

同一模拟运行固定引用原 manifest；后续修订生成新 manifest。对于无关来源的全局 commit 更新，不应无条件重写完整研究文件；先由系列版本证明目标范围没有变化，再复用文件并明确其原始快照身份。不能为复用把旧文件的 commit 改成当前 commit。初版可保守失效，多余重建属于速度问题，错误复用属于准确性失败。

研究接口返回已发布快照身份与准备进度，取消不会发布部分结果。DuckDB 在独立有界工作器执行，不能阻塞行情应用 actor，也不能接受未受控 SQL、外部路径或网络扩展。快照生命周期保护仍被运行引用的文件，不实现无证据的自动删除。

量化指标和模拟应直接使用这份固定输入，而非形成不被产品使用的独立导出。昂贵的递推/窗口计算不得持续占有在线库读事务：在一次短时 MVCC 扫描中有界导出并验证，发布后释放读视图，再从不可变快照计算。这样既固定了输入版本，又避免长计算阻止在线库旧页回收。已有检查点的增量范围同样绑定原系列与修订证据；需要重新计算旧修订时生成对应新版本，不混用旧检查点和新输入。storage_sol 与 drawing_sol 共用 QuantInput/CanonicalScanSummary 合同完成接线。

验收使用同一 native MVCC 与直接 Rust 扫描作独立对照：全范围行数/hash、负价、0/NULL、MAX 加极小数、负 epoch 与完整 u64、半开边界、并发修订/追加、取消及发布前失败/强制退出、重启读取。分别测首次发布、重复复用、修订后重建、宽值 fallback、并行行情的尾延迟；对所测路径报告具体速度，不使用早先独立数据库基准替代运行时结果。
