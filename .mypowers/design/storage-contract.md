# Rust 存储重构的约束与选择边界

关联：[REQ-0011](../requirements/REQ-0011.md)、[REQ-0012](../requirements/REQ-0012.md)。本文先固定正确性与职责；引擎排名等待项目基准，不能视为已经部署。

## 业务与权威状态

本项目当前是行情和量化分析终端，回测仅模拟，实盘下单不在本次范围。所需持久数据是原始来源响应、确定性处理顺序、报价与分钟事实、来源路由和配置、回放/回测参数与证据、研究数据和分析结果。不能因参考资料描述交易系统而额外实现实盘交易账本。

实时解析、同源状态更新和指标计算使用 Rust 进程内状态。数据库、Redis、网络分析请求均不得成为逐事件访问当前状态的必经路径。一次状态更新只有一个写入者；历史下载、查询扫描和 AI 调用在独立的有界执行路径上运行。浏览器关闭或卡顿不改变后台采集；展示合并不能删除规范事件。

原始帧顺序与交易所序号不同。记录来源、连接会话、来源序号（若上游提供）、原始行情时刻及其精度、本地接收时刻、实际应用序号和模式版本。没有上游逐笔能力时，不把分钟快照标成逐笔；源时间不以接收时间替换。保留同戳多个不同事件，不以时间戳单独去重。

## 数值和修订

规范价格和数量保留无损十进制；非十进制计算只适用于明确标为估计值的统计模型，不能回写行情事实。固定刻度整数仅在已验证范围、单位和刻度内使用；转换必须检查可整除与溢出。通用存储不能无条件把 Rust Decimal 的 28 位小数缩至现有数据库的 18 位小数。必要时保留整数系数与小数位数；查询投影的固定 Decimal 类型须有明确可表示性校验。未知成交量使用 NULL；零只能来自确认为零的来源字段。

数据库和客户端之间的宽整数、纳秒时间与十进制不能经过 IEEE-754 double 中转。JSON 中供 JavaScript 运算或精确显示的值使用明确的字符串/单位契约；图表坐标的显示近似不得成为后端计算输入。

可修订分钟事实的键包含来源、品种、周期和时间。源版本、规范 revision、最终状态和实际投影序号各自保留。重复原始帧不增加 revision；陈旧修订不覆盖新版本；权威更正可以降低旧 high 或提高旧 low。查询必须先选择每个事实的有效版本，再聚合，不能对后台尚未合并的多版本重复求和。同花顺日统计仅是报价补充字段，不能再生成一次价格事件或分钟成交量。

## 持久化与可见性

明确区分已收到、已应用、已写入操作系统缓存、已同步落盘、已查询可见。速度比较不得用更弱的持久化级别换取排名。正常退出尽量排空已接受队列；异常恢复从最后完整提交边界继续，重放必须幂等。当前单机测试不能证明整机损坏或磁盘失效下的零丢失，也不冒充这种保证。

每个存储投影的已提交序号只能在该批事实已成功提交后前进。跨存储采用可重放输入和明确的提交水位，不能假设异步写入之间天然有事务。历史页面、指标、回放与 AI 输入带同一数据版本；回补覆盖成功不等于该范围每分钟必然有行情。失败不登记完成，空响应不虚构权威尾部。

原始帧的保留范围须可查询。有限保留不能被称为永久事件档案；淘汰前不得破坏尚未提交投影的恢复输入。文件校验和、存储元数据和游标的提交顺序必须覆盖崩溃中断，不能只测试正常退出。

## 基准与引擎选择

在线时序候选包含 QuestDB、ClickHouse 和合理批次/索引的 PostgreSQL；本地研究与归档比较 DuckDB/Parquet。原生有序键值候选加入 redb，验证无网络边界的范围读、MVCC、单写者事务与 Immediate 持久化，不能因同为 Rust 就预先选定。SQLite WAL FULL 是配置与小事务的语义比较对象，未跑同负载时不列实测排名。kdb+/q 因其时序与列式能力进入候选，缺少可用许可时明确未实测，不能以成本理由排除或宣称已胜过它。

Redis 用于需要跨进程共享的完整版本快照时评估；单进程自身读取当前状态优先直接内存访问。持久日志另比较发布确认与 fsync 语义，不以 NATS、Redis Streams 或 Aeron 的默认确认代替落盘证据。

基准覆盖最新 N 根、排他游标翻页、时间范围、同源 OHLCV、版本修订、原始事件顺序、查询与写入并发、故障恢复。数据集必须包含 NULL、小数极值、同戳事件、重复、乱序和已完成后的更正。记录设备、版本、资源、客户端协议、数据规模、预热方式和完整结果摘要。正确性未过关的结果不进入性能排名；最终选择对应实际业务，而不是只给数据库一个总分。

尾数与 scale 无损存储不等于所有聚合都精确。29 位整数和 28 位小数混合运算可能需要 57 位精度；固定 DECIMAL(38,18) 的通过只覆盖该类型范围。通用路径须采用足够宽的精确运算，或经过验证的逐品种刻度与 checked fallback，禁止 DuckDB 浮点除法或有限范围 Rust Decimal 溢出后被当作精确结果。NULL 的已知部分求和须同时返回已知数量与总分量数量，不能冒充完整成交量。

并行开发期间的探索测量记录机器竞争和 Docker/原生差异；最终候选关键指标在后台构建停止后按同条件复测。进程 SIGKILL 恢复与主机断电/磁盘失效分别说明，不能相互代替。
