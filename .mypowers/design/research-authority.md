# 研究图与外部证据的共享 Rust 输入

2026-10-03 总控设计，补齐 REQ-0006/0009/0010 的现有研究产品路径。实施归 drawing_sol，recovery_sol 提供规范存储接口；不把暂时隐藏浏览器指标作为完成。

## 已有研究查询

研究端继续按来源、资产、证券、周期、复权、before 和范围查询；服务器生成输入，浏览器只提交查询或服务器返回的快照 ID。不能接受浏览器上传的 OHLC 作为权威事实，也不能给普通文件缓存虚构 live Store 的 MVCC 版本。

每次成功获取后，在裁剪展示页以前保存该次可用的规范范围，产生不可变的研究输入 manifest。身份包含完整查询、来源/实际 feed、获取时刻、可用首末时间、原始响应或工作器输出的摘要、规范行摘要、解析器/精度/日历版本、行数、被拒绝行数、分页能力和范围完整性。所有价格和数量输出为精确十进制字符串，未知值仍是 NULL；工作器上游已经丢失的精度不能通过补小数位声称恢复。

规范输入文件与 manifest 在独立临时路径写完并同步，校验行数/hash 后原子发布并同步目录。当前按 query 覆盖的短期 JSON 缓存仅用于新鲜度和发现；已发布输入 ID 不随同 query 的下次刷新改变，也不能被“最多 256 个缓存文件”清理连带删除。失败/陈旧展示可继续引用旧 manifest，明确其旧获取时刻；不得给旧数据换新版本时间。

共享 Rust 适配器扫描该不可变文件，给出真实的 research manifest 身份、FinalRevisionHistory 语义及无 capture 前缀的事实边界；可通过单独 authority 类型，或明确 research 命名空间的 SnapshotToken 表达，但不能冒充 live MVCC。指标/模拟参数、输入范围和公式均进入 hash。该次源只返回近期窗口时，声明 available coverage、warmup_complete=false 和具体历史范围，不能把“读取完文件”写成上市以来完整历史。递推指标使用该声明前缀初始化，与 live 核心共享公式；UI 展示其预热证据。向前分页产生不同时间取得的页，不能不经新 manifest/显式派生规则就拼成同一时刻快照。

QuantInputRequest 可增加明确的 research snapshot 引用分支；禁止把引用和不匹配的 code/source/period/adjustment 混用。主图、研究图、AI 和模拟统一调用共享 Rust evaluator。AI 引用已经发布的指标 input_hash，不重新抓一份当作同版本。原生 source month/week 的 bucket_end 按真实日历计算，不能用固定 31 天表示每个月。

验收包括源查询隔离、复权隔离、同 query 刷新后旧 ID 不变、NULL/负价/宽精确值、分页旧响应、取消、文件篡改/未发布文件、重启后同输入同 hash，以及研究图实际读取服务器指标。取得历史不足可以作为可见的数据边界，未实现适配器不能作为数据不足。

实际页面验收的补充合同：向前加载的更多历史不能永久只进入图表而不允许参与研究。将已校验、同scope的多个页manifest按明确规则发布为新的派生authority，保留每页ID、获取时刻、来源摘要与合并规则。相同时间键相同值去重；冲突不暗中选择，拒绝发布并给出冲突证据。新版本是不同获取时刻的最终修订历史集合，不声称共同上游MVCC或历史当时可见性。明确操作或自动发布成功后，图表、指标、AI和模拟一起绑定新ID；失败则保留旧权威版本并展示原因。原始页与旧authority均可审计，分页扩展不篡改旧输入。真实腾讯股票300→600根流程是该合同的验收入口。

## 外部三类上下文

多周期、VIX/GVZ 与量仓上下文进入同一规范读事务的证据，不能在已生成 token 后临时请求 HTTP 拼接。recovery_sol 与 drawing_sol 固定一个有类型的外部事实记录/命名空间接口：scope、kind、实际来源、observed/published/received 时刻、获取/导入证据、精确值或明确模型值、可用性原因、记录身份与修订。身份不可依赖易碰撞的原始冒号拼接；重复输入幂等，后来的修订保留旧证据。

服务器取得真实外部输入后，先写入同 Store 事务并推进版本，再由 quant 的同一个 read view 选择截止点以前已知的记录。历史模拟只能使用当时已知的版本，不能给修订后的历史值填造早期 received_at；只有“最终历史”来源的输入应明确其语义和原始可知时间不足。事件回放仅使用该 capture 前缀自身可得的外部证据，不读当前 live 外部表。

多周期优先从同来源规范分钟事实在当前读事务内聚合，声明各周期已闭合范围；量仓须保留来源字段语义及实际时间，禁止把累计量当分钟量；VIX/GVZ 保留独立来源和发布时间，来源不可访问时给具体 unknown。外部上下文仍不进入未经批准的合成信号或模拟成交。当前量化适配器恒空 external_facts 属于待接线，不能据此把所有来源永久标为不可用。

外部历史读取需要有界扫描和索引，不向每个批次复制整个无界历史；若初版有明确容量限制，超限应报告而非静默丢失早期证据。准确性验收包含晚到/修订/同戳不同记录、cutoff 前后、未知发布时间、来源隔离及原始回放前视检查。
