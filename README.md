# TraceFang

面向股票、ETF、期货和期权的本地研究终端。首页按「多市场研究 / 实时终端 / 期权策略 / 数据中心」组织工作流。已有实时采集、证据存储和回放继续保留；新研究接口直接使用各来源原生周期，不再用分钟补取链承担股票日线首屏。

## 多市场研究工作台

- 45 个常用观察品种，可搜索、自选、按代码打开；Tushare 可同步指定交易所股票、期货、期权目录。
- 腾讯证券、东方财富：沪深股票、ETF、指数日/周/月线及显式复权；新浪：国内期货原生日线；AKShare：国内期货分钟线、期权日线与 ETF / 股指 / 商品期权链；Tushare：国内多资产日线；Alpaca：美股/ETF 与期权历史数据和期权链。
- 本机磁盘缓存、同请求合并、来源节流、可取消切换、有界向前分页；失败保留同源旧缓存并标注。数据质量页列出截止时间、读取时间、缺失量、来源和复权口径。
- 九类绘图：趋势线、射线、水平线、垂直线、平行通道、矩形、斐波那契、文字与价格/时间测量。支持端点编辑、整体移动、强弱磁吸、锁定、连续绘制、删除和撤销/重做，按品种上下文保存。
- 13 种期权策略模板、多腿编辑、真实链导入、精确到期分段损益、盈亏平衡与无限风险识别、欧式 Black–Scholes / Black–76 理论 Greeks、组合导出。
- Rust 共享指标计算绑定完整权威输入与参数版本，AI 和历史模拟使用同一证据身份；图表显示窗口可以较小。研究向前加载后发布新的不可变输入版本，保留分页来源与读取时刻，不宣称上游共同事务。AI 提供状态、取消、模型选择及报告导出。

公开接口不保证可用性或实时性；连续合约不是可下单月份合约。Alpaca 股票固定使用 IEX 单交易所数据，期权链固定使用 indicative 指示性延迟报价。授权源未配置时显示配置状态，不使用演示价格填充。完整审计与实现说明见 [改造方案](docs/platform-upgrade.md)。

在被忽略的 `.env.local` 中按需设置 `TUSHARE_TOKEN`、`ALPACA_API_KEY` 和 `ALPACA_SECRET_KEY`，重启服务后在「数据中心」测试读取。已安装的独立运行版本需要通过 `update.command` / `update.cmd` 同步代码和配置。AI 继续复用本机 Codex 登录与额度。

快捷键：`T` 趋势线、`H` 水平线、`R` 矩形、`F` 斐波那契、`Esc` 退出画线、`⌘/Ctrl Z` 撤销、`⌘/Ctrl Shift Z` 重做。导出的 K 线包含来源与复权口径；期权 JSON 使用 `unlimited` 表达无上限风险。

### AKShare 国内行情

AKShare 随应用依赖安装，无需 Token。在多市场研究里选择 AKShare，可读取期货
1 / 5 / 15 / 30 / 60 分钟及日线、期权日线、股票与 ETF 日 / 周 / 月线。
分钟行情来自新浪近期历史窗口，不能据此判断上市以来的数据完整；股票和 ETF
仍使用东方财富上游，可在其连接失败时手动切换腾讯。不同来源的 K 线不会混合。

「期权策略」默认选择国内 AKShare 链，支持 50ETF、300ETF、沪深300 / 上证50 /
中证1000 股指期权及黄金、铜、豆粕、白糖等商品期权。先选择标的与有效合约月份，
再加载报价。实际到期日、合约乘数、币种和对应标的由 OpenCTP 目录核对，黄金等品种
的标的月份与期权到期月份分开显示；郑商所三位月份代码与新浪四位代码显式映射。
三位代码必须由有效目录确认年份；查询已到期合约时请使用明确的两位年份新浪代码。
首次导入真实合约会替换模板，买入取卖价、卖出取买价，无盘口时取最后成交价。
缺失或零值报价显示缺失；过期报价缓存可查看，但不能导入策略。

商品期权按 Black–76、ETF 与股指期权按欧式 Black–Scholes 做理论情景分析。
来源未给出的 IV、Greeks 或报价时间保持缺失；读取时间不当作成交时间。
标的参考价只作为情景初值，缺失时需要手工填写。「同步合约目录」的 AKShare
期货目录只包含期权目录关联的商品期货标的，并非全市场期货主数据。

## 保留的实时能力

- 自有品牌的桌面行情工作台：品种观察、实时报价、当前 K 线实时生长、收盘倒计时、当前价聚焦、缩放/平移与 1/5/15/30/60 分钟聚合；
- 可持久化的自定义观察列表：侧边栏不再硬编码品种分类，可从完整目录搜索、添加或移除品种，并由列表自动维护实际的上游订阅；
- `USDCNH` 作为独立实时外汇品种；`XAUCNHG` 由 `XAUUSD × USDCNH ÷ 31.1034768` 实时换算为离岸人民币/克，并明确标记为应用换算值；
- `AU8888`（沪金加权）与 `AG8888`（沪银加权）通过同花顺公开结构化接口直接采集，分别以人民币/克和人民币/千克计价；它们是加权指数观察值，不是可下单的具体月份合约；
- `AU2610`、`AG2706`、`USDIND`、`BRN0Y`、`SHCOMP` 与 `IXIC` 通过同一公开源读取实时报价、日内统计和同源分钟 K 线；跨市场 K 线按上海、纽约、伦敦或 UTC 的源时区解析；
- 每个合约独立且仅保存一个实时数据源绑定；完整实时数据源必须同时提供 `quote + kline`，内部通道构成不暴露为合约选项；
- 金十统一行情向页面输出一份来源结果，内部原始通道分别落库且绝不静默互相代替；
- 当前与过去 K 线都服从合约绑定；普通查询只读专属本地缓存，缺失覆盖由后台仅向同一实时数据源补取、落库后再显示，不跨源标准化、补缺或回退；
- 实时请求或订阅只绑定一个明确来源，断线时标记停滞，不自动换源；
- 浏览器通过 WebSocket 接收持续报价事件；报价 REST、WebSocket 首帧和 K 线 GET 都只读本地。页面在发现历史覆盖未记录时调用隔离的普通回补 POST；同一交易时段内已进入视窗的具体 Bar 缺口可执行一次精确同源复核，两者都不阻塞实时链路；
- 原生候选使用本机 redb 保存原始捕获、规范事实、路由与恢复水位；同一读事务提供行情和版本证据。Parquet 保存可复用的不可变批量输入，DuckDB 只执行受控查询。旧 PostgreSQL/NATS 原件作为迁移证据保留；
- 实时数据源管理：合约级单选绑定、完整能力、健康状态、运行要求和连通测试；
- 金十官方 MCP 适配代码仅作归档保留；应用不读取其配置、不注册来源、不初始化，也不用于实时、历史或校对；
- 金十官网高速行情：直接接收金十官网公开结构化 WebSocket 的价格变化推送，无需 Token 或桌面客户端；
- 金十桌面会话行情：使用本机金十客户端会话鉴权并解码 WebSocket 二进制报价，支持心跳、断线重连和源时间；截图与 OCR 已从生产代码中删除；
- 黄金重要数据与事件事实库：统一保存计划/实际/有效期/发布时间与修订版本，事件显示和资金主导策略独立，并以冲击分、趋势分和证据覆盖率评估已发生事件；
- 通用领域模型、能力端口和适配器边界，方便继续接入期货、股票、外汇、加密资产和其他供应商。

## 原生运行与安装

当前原生版本已完成隔离候选及真实旧数据只读接口验收；正式 8000 服务的交接尚未执行。
首次从旧 Python/PostgreSQL/NATS 安装迁移时，必须先固定原始输入、核对停止后的事实并写入
已验证交接边界。安装入口会拒绝直接替换仍在采集的旧服务，候选与失败证据都会保留。
这项限制不影响在独立端口准备和验证候选。

构建环境需要 uv、Rust/Cargo 和提供 corepack 的 Node.js。原生后端日常运行不启动
PostgreSQL、NATS 或 Docker。Python 虚拟环境仅供 AKShare 等隔离数据工作器及管理入口；
网页由 Rust 后端提供，正式运行不常驻 Vite。固定依赖和 DuckDB 1.5.6 随准备流程核验。

先同步管理入口依赖，再准备候选；这一步不会停止当前服务：

```sh
uv sync --frozen
PYTHONPATH=src .venv/bin/python -m tracefang.service prepare
```

准备过程从固定源码快照构建 Rust 和网页，立即保存独立二进制，发布源码、锁文件、静态产物
与构建身份清单，再用禁采集的隔离数据目录启动、核对 `/api/ready` 并正常退出。
输出的 `release-*` 目录包含 `release-manifest.json` 与 `candidate-validation.json`。
配置秘密只进入本机受限文件，不写入发布清单或源码归档。

完成旧数据交接后，可启用已经准备的具体版本：

```sh
PYTHONPATH=src .venv/bin/python -m tracefang.service activate --runtime /absolute/path/to/release-directory
```

后续日常入口对应如下。`update` 重新准备候选后才尝试切换；`restart` 使用已安装版本，
不会部署工作区改动。首次原生迁移仍受上述交接检查约束。

| 操作 | macOS | Windows |
| --- | --- | --- |
| 打开 / 启动 | `start.command` | `start.cmd` |
| 停止 | `stop.command` | `stop.cmd` |
| 查看状态 | `status.command` | `status.cmd` |
| 准备并部署本地更新 | `update.command` | `update.cmd` |

macOS 正式注册直接执行版本目录中的 `bin/tracefang-server`。注册、启动与检查完成后，
一次性 Python 管理入口退出；必要的 AKShare 工作器按需运行。Windows 使用当前用户任务
及进程监督器管理 Rust 子进程，保留退出码与终止清理；兼容单测已执行，Windows 实机的
注册、恢复和效能尚未验收。

持久原始捕获、事实库、量化结果与批量输入放在运行版本之外：macOS 默认位于
`~/Library/Application Support/TraceFang`，Windows 默认位于 `%LOCALAPPDATA%\TraceFang`。
可显式配置 `TRACEFANG_DATA_DIR`、`TRACEFANG_STORE_PATH`、`TRACEFANG_CAPTURE_PATH`、
`TRACEFANG_QUANT_RESULTS_DIR` 与 `TRACEFANG_BATCH_SNAPSHOTS_DIR`。编译缓存使用系统缓存
目录或 `CARGO_TARGET_DIR`，不作为行情原件。旧运行版本和旧数据不会因准备失败被删除。

`/api/ready` 核对实际构建身份、持久路径、已验证索引、捕获缺口和投影恢复边界。
只读核验显示 `production_ready=false`，不激活事实 generation，也不写交接边界。
正式服务就绪不等于上游正在报价；休市、陈旧与未测试状态另行展示。
新候选失败后，只有证明原始尾、事实版本和格式政策均未变化，才自动恢复上一原生版本；
已接受新输入或无法证明安全时保持停止，保留全部候选与数据，不自动重启旧 Python 采集。

浏览器关闭只结束展示；`stop.command` / `stop.cmd` 停止系统托管的后端并保留数据。
`TraceFang.app` 与 Windows `TraceFang.vbs` 是独立的应用窗口入口，其窗口会话负责启动和
停止；原先应用窗口与容器的性能记录属于旧 Python 阶段，不用于证明本轮原生安装。
当前及历史验证边界见 [启动器验证记录](docs/launcher-validation.md)。

开发入口是 `python3 scripts/run-local.py --dev`，协调 Rust API 与 Vite，任一退出会停止
另一个。使用正式端口前先停止对应正式服务；需要同时运行时使用独立端口和独立数据路径。
开发入口不启动旧容器。

### 本机配置与 AI

进程环境变量优先于 `.env.local`，后者优先于 `.env`；两份文件均被 Git 忽略。
在其中按需设置研究来源 Token、客户端会话或代理，然后重新准备运行版本。
金十公开实时报价无需 Token；历史回补和日内补充需要桌面会话，macOS 可复用已登录
客户端。显式 `JIN10_LOCAL_SESSION_TOKEN` 优先；其他平台或非标准安装须显式配置。

AI 复用本机 Codex 登录，不要求另存 OpenAI API Key。可用 `TRACEFANG_CODEX_CLI_PATH`
指定 CLI，未指定时查找 `PATH` 和 macOS 标准应用安装路径。模型目录通过本机
`codex app-server` 读取，推理经临时 `codex exec` 会话进行，不修改个人 Codex 配置。
模型与推理强度以本机返回能力为准；问题最多 8000 字符，浏览器只保存模型偏好。

发送内容包括完整历史计算后的当前指标/策略结果、参数、输入与快照摘要、来源、截止时刻、
外部证据和限制，以及最多 32 根必要的近期 OHLCV；不会重复发送全部图表指标序列。
完整输入与快照仍保存在本机供审计。研究、回放和实时上下文使用各自的权威版本，
原始事件回放不静默替换成当前实盘数据。临时会话使用只读沙箱与禁工具分析约束；
只读沙箱本身不等于文件读取隔离。推理联网并使用当前账户额度，当前返回完整响应。

页面区分浏览器到本机服务的断线与具体上游故障。临时断线采用有界退避，协议拒绝不会
无限重试；未验证的连接不显示测试成功。

客户端会话是本机敏感凭据：真实 Token 不得提交、复制到文档/聊天、写入测试、日志、数据库、API 响应或 Git 历史。解析器只在后端内存保存凭据快照，并拒绝符号链接、目录外或非当前用户拥有的自动发现文件。macOS 客户端重新登录并轮换 Token 后，下一次鉴权失败只刷新会话并重试一次；仍失败则进入明确的鉴权错误和退避，不推进任何历史覆盖。显式环境值变更后应重启后端。若 Token 曾暴露到可留存位置，建议立即轮换。

## 数据源使用方式

- 实时路由粒度是“合约”。切换合约时恢复该合约唯一的实时数据源绑定。
- 来源菜单是单选列表；选择新实时数据源会原子替换旧绑定，不存在多个来源同时绑定、优先级回退或 `auto`。
- `测试连接` 面向完整实时数据源，同时验证报价和 K 线输出；内部 Web/桌面通道不作为两个可选虚拟源展示。
- 实时采集由后端合约路由常驻管理，与浏览器订阅数量无关。实时数据源把实际需求映射到内部推送通道；启动时会把遗留的物理通道或 MCP 合约绑定迁移到默认实时数据源。
- 实时 REST/WebSocket 首帧只读本机已提交事实与报价，不因普通查询调用上游。主动连接测试按来源能力执行实际探测；不支持探测的来源明确显示未测试。
- K 线 GET 先解析合约绑定，再只读取该实时数据源的专属内存/数据库缓存，并返回服务端不透明排他游标。页面先显示最新 500 根；每次左缘动作只提交一个以逻辑 Bar 表达的 `countBack` 历史命令，服务端先读本地、必要时执行一个最多 10000 分钟的同源传输步骤、增量物化并直接返回周期页。浏览器不再换算分钟或串联多个回补/准备请求。后端只请求当前绑定源自己的缺失差集，把原始 K 线、统一 Bar、覆盖与权威状态写入原生持久证据；普通 GET 保持只读，实时尾部只重算受影响桶。前插保持用户当前视窗与实时跟随状态。同一交易时段内的可见缺口可以只复核精确子区间，跨会话休市不会触发。
- 当前柱由该实时数据源的同源 K 线状态与报价事件共同生长：同秒到达的多帧全部参与开高低收；跨周期后的第一笔报价独立开启新柱，不沿用上一柱收盘价。倒计时每秒更新，不额外调用数据接口。
- 浏览器通过 WebSocket 持续接收本地事件；REST/WebSocket 都不接受来源参数，只服从合约绑定。MCP 服务不会创建客户端、握手、轮询或执行任何工具调用。
- 金十统一行情由上游事件驱动，不做 0/5/10 秒固定轮询，也不会在任一内部采集适配器断线时跨来源补值。
- 金十统一行情归类为“优质分析级”。其实时报价使用公开网页行情协议的变化驱动档；2026-08-06 实测黄金 30 秒收到 70 帧，平均约 3.68 帧/秒；本机后端接收至网页采样器平均 1.27ms。它适合常规分析，但不等同于有明确低延迟 SLA 的机构专业级数据。
- 图表工具栏的来源下拉框同时承担管理控制台：可测试、查看运行状态，并为当前合约单选实时数据源，不再打开独立管理页面。

合约的实时数据源绑定和观察列表保存在原生事实库中；每个合约至多一个实时绑定，配置操作先持久提交再发布到运行状态。品种目录通过 `GET /api/instruments` 读取，观察列表通过 `GET/POST/DELETE /api/watchlist` 管理。接口契约见 [docs/source-management.md](docs/source-management.md)，图表历史状态机见 [docs/kline-history-loading.md](docs/kline-history-loading.md)。

## 旧 PostgreSQL 数据（迁移原件）

以下描述保留旧安装的存储结构，不是原生后端的运行依赖。旧容器与数据卷仅在明确维护操作中处理；原生启动和停止不会删除或操作它们。


本地容器默认只绑定 `127.0.0.1:15432`，使用低于 Windows 默认动态端口范围的本机专用端口；可在被 Git 忽略的 `.env.local` 中修改。原始报价先在同一事件循环轮次更新内存报价/K 线并推送页面，再由有界队列异步写入 PostgreSQL，不把数据库延迟放进实时热路径。`quote_events`、`latest_quotes` 与 `candles` 是分渠道证据层；`realtime_candle_cache_ranges` 记录同一实时数据源已完成的永久历史检查范围，包括成功但零行的休市区间；`realtime_bar_series_state` 保存排他 `authoritative_through`、可选 `history_floor`、可变尾部软检查和证据版本。二者均在历史批次的同一短事务中更新，数据库失败不会先把未持久化历史发布到内存。`derived_period_bars` 保存派生周期页，`period_bar_materializations` 保存对应事实游标和物化边界，使重复读取无需全量聚合。覆盖表示“上游已成功检查”，不保证区间内每分钟都有 Bar；同一交易时段内的具体可见缺口允许冷却受控的精确同源复核。`candle_validation_results` 与 `standard_candles` 暂时冻结，不参与查询。
